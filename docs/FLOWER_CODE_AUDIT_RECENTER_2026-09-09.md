# Re-flowered Monster audit — implementation recenter

The first audit was itself pressure-tested against the Constitution and the current evidence hierarchy.

## What survives the second Flower
The central risk is no longer missing feature families. It is **composition drift**: a mechanism can be certified in isolation yet omitted by a downstream runner. The environment half-wiring is direct evidence of that risk.

The architecture should therefore move from "many correct modules" toward "one canonical reality composition." A feature is only active when source -> compiler -> mechanism -> world jurisdiction -> artifact is continuous.

## Priority order after recursion
1. **Composition integrity** — repair environment propagation now and establish a reusable canonical helper.
2. **Single-path production** — progressively retire monkey-patch composition in favor of a shared Reality-v1 builder. Do this incrementally so existing certified kernels remain comparable.
3. **State freshness** — injury/weather refresh dominates marginal model sophistication before lock.
4. **Allocator causality** — next major kernel revision should separate player-specific role uncertainty from conditional effectiveness and constrain TD recipients to actual world events.
5. **Only then add more evidence families** — wingspan, travel/rest, surface, deeper coaching/scheme or assignment matchups require trustworthy evidence plus causal validation.

## Anti-overfitting decision
Do not tune coefficients because a new output "looks better," and do not tune toward Vegas. Preserve the blind model. The comparison after this repair is diagnostic: we expect weather-sensitive games and their pass distributions to move modestly, domes to remain unchanged from this mechanism, and aggregate opportunity conservation to remain intact.

## Definition of success for this implementation pass
- canonical environment helper exists;
- Reality-v1 game runner and fantasy-complete runner both use it;
- tests prove correct jurisdiction and dome null;
- production suite passes;
- a fresh current-state simulation succeeds;
- new player distributions are compared to the pre-Madden baseline and the immediately previous Full-Reality run;
- any movement is explained by mechanism jurisdiction rather than treated as automatic improvement.
